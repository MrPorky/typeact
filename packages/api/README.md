# `@typeact/api`

The typed fetch client for typeact Contracts — `createClient`, the `Result`
outcome type, SSE / NDJSON / WebSocket support, and the `onEvent` stream helper.
Calls are addressed method-first by `(method, path)`.

```bash
vp install @typeact/api @typeact/core
```
