# `@typeact/core`

The Contract definition language for typeact — `createRoute`, `createContract`,
path utilities, and `InferRoute`. Its only dependency is `@standard-schema/spec`,
which it re-exports so the rest of the ecosystem imports the spec from here.

```bash
vp install @typeact/core
```

📖 **Full documentation:** [`apps/website/packages/core.md`](../../apps/website/packages/core.md)

This README is intentionally a stub. All API reference and examples live in the
website, which is the single source of doc truth (see [ADR-0006](../../docs/adr/0006-docs-single-source-type-checked.md)).
